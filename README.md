# ascii-movie

Play a pre-converted ASCII animation directly in the Linux terminal.

## Installation

Run this command(one command instalation):

```bash
curl -fsSL https://raw.githubusercontent.com/mkarmannyi-ui/ascii-movie/main/install.sh | bash
```

Or clone the repository:

```bash
git clone https://github.com/mkarmannyi-ui/ascii-movie.git
cd ascii-movie
